## The licence
**UI translations** contributed on the Cycling Commons website — proposed and approved
renderings of existing interface strings into an enabled non-English locale — are made
available under the **Creative Commons Attribution-ShareAlike 4.0 International licence
(CC BY-SA 4.0)**.

Anyone may **share and adapt** those translations, including commercially, provided they:
1. **Attribute** the Cycling Commons (and the translator if they are credited); and
2. **Share alike** — distribute adaptations under CC BY-SA 4.0.

Why a different licence from the data and the code: ODbL is built for *databases*; PolyForm
Shield covers the *software* (including the developer-shipped locale YAML in git). CC BY-SA
is built for *creative works*. Website-submitted UI translations use CC BY-SA — the same
open, share-alike deal as media — and live in the database as proposals and overlays, not in
git YAML.

## Required attribution
> UI translation by **[translator]** (or anonymously), via the Cycling Commons, licensed under
> CC BY-SA 4.0.

## Provenance — the hard rule
A UI translation may enter the Commons **only** if the contributor has the right to license it.
- Your own wording of an existing catalogue key: yes.
- Copying someone else's copyrighted translation, scraped or re-hosted from another site: **no.**
By proposing a translation you confirm you hold these rights (see the Terms clause).

## Scope
Covers website-submitted UI translations only (proposal and overlay rows in the database). It
does **not** cover:
- the developer-shipped locale YAML in git (`web/translations/messages.*.yaml` — PolyForm Shield,
  part of the software);
- personal data (private, never published);
- the underlying factual data (ODbL — see `COMMONS-DATA-LICENSE.md`);
- contributed media (CC BY-SA — see `COMMONS-MEDIA-LICENSE.md`); or
- any proprietary software and branding built on the Commons.
